# ShoKKo&Latte Telegram Bot

## Описание

ShoKKo&Latte — это Telegram-бот для кофейни, который позволяет пользователям:

- Просматривать актуальное меню
- Узнавать, как нас найти (с картой)
- Связаться с менеджером

## Структура проекта

- `bot.py` — основной код бота
- `Procfile` — конфигурация для Heroku/Render
- `render.yaml` — конфигурация для Render
- `amvera.yml` — конфигурация для Amvera
- `requirements.txt` — зависимости Python
- `runtime.txt` — версия Python
- `.env.example` — пример файла с переменными окружения
- `assets/` — изображения и шрифты

## Установка и запуск локально

1. Клонируйте репозиторий:
   ```bash
   git clone <URL-репозитория>
   cd ShoKKoLatte
   ```

2. Создайте виртуальную среду (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\\Scripts\\activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Редактируйте `.env`, заменяя `your_telegram_bot_token_here` на реальный токен бота от @BotFather.

5. Запустите бота:
   ```bash
   python bot.py
   ```

## Деплой на Render

1. Подготовьте репозиторий на GitHub.

2. Перейдите на [Render](https://render.com) и создайте новый проект.

3. Выберите «Static Site» или «Web Service» в зависимости от типа проекта.

4. Подключите репозиторий GitHub.

5. Укажите корневой каталог (по умолчанию — `ShoKKoLatte`).

6. В настройках добавьте переменные окружения:
   - `BOT_TOKEN` — токен бота
   - `MANAGER_USERNAME` — имя пользователя менеджера (например, `@Jabby`)
   - `WELCOME_IMAGE_URL` — URL-адрес изображения для приветствия (необязательно, если есть `assets/welcome.png`)

7. Нажмите «Создать» и дождитесь сборки.

## Деплой на Amvera

1. Подготовьте репозиторий на GitHub.

2. Перейдите на [Amvera](https://amvera.io) и создайте новый проект.

3. Подключите репозиторий GitHub.

4. В настройках укажите:
   - Язык: Python
   - Версия: 3.12
   - Требования: `requirements.txt`
   - Команда запуска: `python -u bot.py`

5. Добавьте переменные окружения:
   - `BOT_TOKEN`
   - `MANAGER_USERNAME`
   - `WELCOME_IMAGE_URL`

6. Разверните проект.

## Переменные окружения

| Переменная | Описание | Обязательна |
|----------|-------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | ✅ Да |
| `MANAGER_USERNAME` | Имя пользователя менеджера (например, `@Jabby`) | ✅ Да |
| `WELCOME_IMAGE_URL` | URL-адрес изображения для приветствия (необязательно) | ❌ Нет |

## Структура кода

- `bot.py` использует [aiogram 3.x](https://github.com/aiogram/aiogram).
- Клавиатура бота настраивается через `get_main_keyboard()`.
- Бот поддерживает команды:
  - `/start` — приветствие с изображением и меню
  - «Меню» — отображает меню кофе и десертов
  - «Как нас найти» — показывает адрес и карту
  - «Позвать менеджера» — запрашивает связь с менеджером
